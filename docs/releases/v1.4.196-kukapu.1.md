## Incidencias

- **rpm**: el `build:linux` nuevo de upstream (`build-linux-local.mjs`) compila `AppImage deb rpm` y falla en el VPS porque no hay `rpmbuild` (`fpm: Need executable 'rpmbuild'`). Solución aplicada: empaquetar directamente `ORCA_LOCAL_BUILD_VERSION=… pnpm exec electron-builder --config config/electron-builder.config.cjs --linux AppImage deb --x64` tras `build:desktop`. El AppImage y el deb ya se habían generado antes del fallo, pero se re-empaquetó para regenerar `latest-linux.yml` consistente.
- **ELF pie**: el binario pasa de reportarse `ELF 64-bit LSB executable` a `ELF 64-bit LSB pie executable`; el sanity check del script de instalación (`grep 'ELF 64-bit LSB executable'`) se ajustó a un patrón que acepta ambos.
- **Automations**: confusión de zona horaria (el job de "las 7" es 07:00 UTC, no hora local); ambos jobs `*-upstream-sync` se movieron a 05:00 UTC y se lanzaron manualmente tras el cambio.
- Instalación y arranque limpios: servicios activos, puerto 6768 escuchando, runtime `ready` con `appVersion: 1.4.196-kukapu.1`. Único ruido: un sweep de worktree-trash quedó a medias (`ENOTEMPTY`) y se limpió a mano.
